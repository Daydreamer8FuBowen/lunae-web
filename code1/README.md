# 须臾集

把见闻、回忆与想象绘成简约水粉画，收进自己的小集。

已集成到 Lunae 工具箱第三个项目，线上入口为 `/tools/xuyu`。主站统一构建与部署说明见根目录 `README.md` 和 `deploy/README.md`；以下命令用于单独运行本目录。

## 本地启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5173/ 。本机已配置 `.env.local`；换电脑时复制 `.env.example` 为 `.env.local`，在文件中填写自己的 `OPENAI_API_KEY`。密钥只由 Node 服务读取，不使用 `VITE_` 前缀，不进入浏览器构建；不要分享 `.env.local`。

```sh
npm test
npm run build
npm start
```

`npm start` 或 `npm run preview` 会在相同本地地址运行构建后的网页和图片接口。运行前先关闭占用 5173 端口的开发服务。需要同时保留 Node 服务、`.env.local` 和 `data/generated/`，仅上传 `dist/` 到静态托管不能生成或读取新画面。线上部署使用独立 Node 服务和持久化目录；目前没有账号和收藏跨设备同步。

## 使用

- 写下 1–240 字的片刻，选择随画面、暖一点或冷一点，点击「让片刻成景」。新文字会通过本地服务提交给配置的图片 API，生成一张水粉画。
- 也可以切换「从照片拾起」，选择一张照片，再点击「让片刻成景」。支持 JPEG、PNG、WebP，原文件不超过 10 MB；浏览器先压缩到最长边 1280 像素并移除元数据。自动识别主体、简化背景，用同一套当代水粉风格和画幅重绘，生成中文画名及配文。可替换或移除待绘制照片。
- 照片流程使用同一服务的 `/responses` 识别（`IMAGE_VISION_MODEL`，默认 `gpt-6-luna`）和 `/images/edits` 参考图重绘。沿用文字生成的图片模型、尺寸和质量；图片服务需要同时支持这两个接口。已使用项目示例图验证这条真实调用链路。
- 使用已验证的兼容接口 `https://token.lunovaai.top/v1/images/generations`，默认 `gpt-image-2`、low、1152×768。提示词直接使用原文，不额外调用文字模型。
- 相同原文、色调、提示词与模型参数复用已有图片；并发重复请求合并。同一时间绘制一个片刻，不自动重试付费请求。
- 生成时显示等待状态；失败时保留原画面并显示错误，可手动重试。生成可能耗时数分钟。
- 示例卡片使用已有水粉图，点击预览不调用 API。点击主生成按钮才会请求自己的画面。
- 「收进小集」保存原文、色调和真实生成图片地址；刷新可恢复最近生成的画面。收藏保存在当前浏览器 localStorage，上限 100 条。
- 「存为图片」导出带文字的 PNG。支持手机布局与减少动态效果。

## 数据和消耗

密钥位于被忽略的 `.env.local`。文字或压缩后的照片仅在用户点击生成时传给配置的第三方图片服务。上传原图不写入磁盘或浏览器存储；压缩照片只在当前页面内存中保留，刷新后需要重新选择。生成图片保存在 `data/generated/`，主体描述和中文配文缓存在其 `analysis/` 目录；使用请求内容哈希命名，服务重启后缓存仍然有效。图片接口只允许本机与同源请求，下载上游图片时不转发 API 密钥，错误信息不暴露密钥或签名链接。

收藏和最近画面的记录保存在浏览器，图片文件在本机，两者要配合使用。清除浏览器数据会移除收藏记录，删除 `data/generated/` 会让已生成图片失效。重要画面建议导出 PNG。

新内容或新色调会产生一次新的付费生成。缓存命中、示例预览、收藏、打开收藏和导出不调用生图 API。服务之前在请求 1152×768 时实际返回过 1536×1024，因此不能根据请求尺寸推断实际账单；费用以服务商为准。默认参数可在 `.env.local` 中修改，修改后重启。

照片首次成景增加一次简短的图片识别调用，同时得到主体描述、画名和配文。相同照片与色调直接复用成品；更换色调或重绘失败后手动重试，会复用成功的识别结果。服务不会自动重试付费请求。文字成景仍只调用生图接口。

## 代码

- `server/image-api.js`：生成接口、磁盘缓存、并发合并和图片读取。
- `vite.config.js`：为开发和构建预览挂载同一服务。
- `src/image-style.js`：统一的简约当代水粉提示词和默认参数。
- `src/generation.js`：前端请求与收藏画面恢复。
- `src/main.js`：创作、收藏和导出。
- `src/scene.js`：示例映射和 SVG 画框；真实生成图片优先。
- `test/server.test.js`：HTTP 生成、缓存、错误、并发和恢复测试，使用模拟上游，不消耗余额。

## 独立生图脚本与已有素材

`scripts/generate-images.mjs` 兼容 URL/Base64 返回，使用当前进程的 `OPENAI_API_KEY`；可通过 `npm run images -- --text '一个片刻'` 运行，`--dry-run` 仅预览请求。该命令不会自动读取 `.env.local`，网页服务则会读取。

`public/art/gouache/` 是十张已有示例 WebP，约 607 KB。原始 PNG 位于 `output/imagegen/project-gouache/`，提示词位于 `output/imagegen/project-gouache-prompts.jsonl`；五种画风对比位于 `output/imagegen/styles/`。保留作示例预览，真实生成不受示例类别限制。
